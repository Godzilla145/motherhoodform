# NLParto — Validation Clinique (Santé Maternelle & Infantile)

Plateforme d'évaluation et de validation clinique directe des dialogues de santé en Darja algérienne par des médecins, internes, résidents et sages-femmes.

## Déploiement en 1 clic sur Streamlit Cloud
1. Connectez votre compte GitHub sur [share.streamlit.io](https://share.streamlit.io).
2. Choisissez le dépôt `Godzilla145/motherhoodform`, branche `main`, fichier principal `app.py`.
3. Cliquez sur **Deploy** !

## Lancement en local
```bash
# Avec Streamlit :
streamlit run app.py

# Ou avec le serveur web autonome :
python server.py
```
